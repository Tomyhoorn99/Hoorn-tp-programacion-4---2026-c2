# Proyecto: Sistema de Cine — Programación IV TP1

## Contexto
- Aplicación web completa para la gestión y comercialización de un cine.
- Debe contemplar clientes, usuarios registrados, empleados y administradores.
- La consigna del TP es la fuente principal de verdad. No inventar requisitos ni eliminar requisitos existentes.

## Tecnologías
- Angular: arquitectura, componentes, templates, control flow, data binding, Inputs/Outputs, Signals, routing, lazy loading, guards, formularios, servicios, RxJS, pipes y directivas.
- Supabase: Auth, Database, RLS, Storage y Realtime cuando corresponda.
- PWA: instalación y funcionalidades requeridas por la consigna.
- GitHub y deploy.
- Otras tecnologías de la cursada (por ejemplo NestJS, MongoDB, JWT, Cookies, Sockets o Cron) no están prohibidas por defecto. Usarlas solo cuando una necesidad real del proyecto o una consigna posterior lo justifique.

## Criterios de desarrollo
- Priorizar código simple, claro y mantenible.
- Preferir soluciones nativas de Angular y Supabase antes de agregar librerías.
- Evitar sobreingeniería y complejidad innecesaria.
- Separar responsabilidades: componentes para UI, servicios para lógica compartida/acceso a datos y guards/interceptores donde corresponda.
- Crear componentes reutilizables cuando exista una necesidad real.
- Mantener nombres y estructura consistentes con el proyecto.
- Toda decisión importante debe poder explicarse en la defensa oral.

## Reglas de trabajo
- Antes de implementar una funcionalidad compleja, revisar sus requisitos y reglas de negocio.
- No modificar arquitectura o tecnologías importantes sin justificar el motivo.
- Cuando haya una ambigüedad de la consigna, señalarla antes de asumir una interpretación.
- Al modificar código existente, preservar lo que ya funciona y evitar cambios no relacionados.
- No agregar funcionalidades "por las dudas".
- Mantener la documentación del proyecto actualizada cuando una decisión arquitectónica cambie.
